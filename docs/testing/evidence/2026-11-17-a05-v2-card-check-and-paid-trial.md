## 1. Method

As the [A05-V recheck](2026-11-17-a05-v-verification-services.md) did it:

- **Fetching.** `curl` (with a browser-style User-Agent) fetched each source into its own new directory in the session's scratchpad, outside the repository. A page that needs JavaScript was rendered with the pre-installed Chromium (Playwright) and its rendered HTML saved the same way; the sources tables mark these "(rendered)". Each fetched file was hashed with SHA-256; no fetched file is committed.
- **Reading.** A Python script run with `-I`, kept outside the fetch directories, stripped the HTML tags and flattened white space (for Apple's documentation, its `.json` endpoints; for Stripe's documentation, its `.md` variants); `pdftotext -layout` read the PDFs.
- **Quotation checks.** A second script searched for each row's quotation, split at its ellipses, as one continuous string in the stripped text, and reported **exact**, or **normalised** where it matched only after normalising white space before punctuation, quotation marks, a line-break hyphen or a bill's line numbers. Each normalised match was then read in place.
- **California's bulk data** (`pubinfo_2025.zip`, 1,292,263,530 bytes, `Last-Modified: Mon, 16 Nov 2026 05:26:36 GMT`, ETag `"4d06606a-6605e05841b00"`, 205,287 members: the same file A05-V read) is too large to download. The server accepts byte ranges, so the zip's central directory, the law section table and only the members needed were read by HTTP range requests; each extracted member is hashed in section 3.
- **One certificate chain completed.** `www.ilga.gov` serves its certificate without the Sectigo intermediate, so `curl` refused it. The intermediate named in the leaf certificate's own Authority Information Access field (`http://crt.sectigo.com/SectigoPublicServerAuthenticationCAOVR40.crt`, SHA-256 `8eb2f17d668941c39a7fca0cee127ae0ebaf444610631cca3cd19eab46c5824a`) was fetched and verified against the trusted bundle (`openssl verify`: `OK`) before the Illinois act was fetched with it. Verification was never turned off.
- **Searches.** The WebSearch tool found URLs and status leads only; a secondary page led to a primary one. A fact resting on a secondary source is marked **UNCONFIRMED**. One public Federal Register search (its JSON API, no key) listed the FTC's negative-option documents since 13 February 2026.
