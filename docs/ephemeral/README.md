# Ephemeral work

Use this folder for single-use Markdown prompts and temporary handoff drafts. Name files `YYYY-MM-DD-work-id-purpose.md` and include the owner, assignment scope, persistent context links and deletion condition. The folder itself contains no required product decisions.

Promote unique decisions, required specifications and lasting evidence before removing a file. Close the assignment, update links and prune through a PR as described in [the documentation guide](../README.md). Active prompts affect agent behavior. A change made only of Markdown skips application CI and code/security review (Nathan, 24 September 2026), so the manager reads every prompt change when it integrates it. Do not put credentials here.
