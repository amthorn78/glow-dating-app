# Ephemeral work

Use this folder for single-use Markdown prompts and temporary handoff drafts. Name files `YYYY-MM-DD-work-id-purpose.md` and include the owner, assignment scope, persistent context links and deletion condition. The folder itself contains no required product decisions.

Promote unique decisions, required specifications and lasting evidence before removing a file. Close the assignment, update links and prune through a PR as described in [the documentation guide](../README.md). Active prompts affect agent behavior and receive full checks/review. Do not put credentials here.
